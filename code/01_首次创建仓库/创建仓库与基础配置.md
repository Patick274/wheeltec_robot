# 文件夹一：第一次创建 GitHub 仓库

1. 注册、安装与配置
在 https://github.com 注册账号；到 https://git-scm.com/downloads/win 安装 Git。
安装 Git for Windows 时保留 Git Credential Manager（GCM），安装后重新打开 PowerShell。
其他系统：macOS 可安装 Git 或 Xcode 命令行工具；Ubuntu/Debian 可执行 sudo apt update 后 sudo apt install git。
本教程的命令示例主要面向 Windows；不要把 PowerShell 的路径命令原样贴到 Bash。

```powershell
git --version
# 输出版本号表示 Git 已安装且可从当前终端找到。
git config --global user.name "你的提交显示名"
# 设置提交作者，不要求与 GitHub 用户名相同，也不是登录账号。
git config --global user.email "你的邮箱"
# 可使用 GitHub Settings → Emails 中实际提供的 noreply 邮箱保护隐私。
git config --global --get user.name
git config --global --get user.email
# 检查本机配置。另一台电脑也要配置一次。
```

2. 创建远程仓库：先决定走哪条路线
命令行 C/D：GitHub → + → New repository，填写名称并选择 Public 或 Private。
有现成的本地项目、准备首次直接 push 时，不预先添加 README、.gitignore 或 license，创建空仓库。
这只是该流程的要求；如果远程已经有文件，直接 clone，再复制项目内容到克隆目录更省事。
不要复制旧项目的 .git，以免把新克隆目录的历史覆盖。
Desktop B：可以由 Desktop 的 Publish repository 创建远程，不必提前在网页创建同名仓库。
网页 A：可在空仓库的 Quick setup 区域点击 uploading an existing file 上传。
创建完成后复制仓库 Code 菜单里的地址，不要凭记忆拼写：
HTTPS：https://github.com/YOUR-USER/PHM.git
SSH：git@github.com:YOUR-USER/PHM.git

3. 项目准备与仓库检查
```powershell
Set-Location -LiteralPath 'D:\Projects\PHM'
# 进入你自己的项目根目录，路径不存在就先选对目录。
git rev-parse --show-toplevel
# 输出已有 Git 仓库根目录；若输出的是父目录，不要继续初始化子仓库。
git status
# 非仓库会报 not a git repository，这是检查结果。
```
目录确实没有自己的或父级的 Git 仓库时，首次上传步骤才使用 git init -b main。
克隆得到的仓库不要再初始化。Git 不记录空文件夹；想保留空目录，可放一个 .gitkeep 文件。
首次提交前建立 .gitignore，可在项目根目录新建 .gitignore，参考本篇末尾的模板。
模板忽略 Python 缓存、虚拟环境、.env、私钥和日志，需按实际项目增删。
不要上传密码、令牌、私钥、原始大数据或模型权重；.gitignore 不会自动移除已跟踪文件。

4. main 与 master
```powershell
git branch --show-current
# 查看当前分支名；尚无提交时 git branch 列表可能为空。
git branch -a
# 查看已有本地和远程跟踪分支。
```
本教程新项目统一 main。已有仓库叫 master，就按实际分支操作，或先评估后改名。
仅确实需要且没有冲突名称时，可 git branch -m main；不要为解决任意 push 错误就强制改名。


## .gitignore 示例

在项目根目录新建名为 `.gitignore` 的文件，将下面内容按需复制进去。

```gitignore
# Python 缓存和虚拟环境
__pycache__/
*.py[cod]
.venv/
venv/
# 本地环境变量与私钥。此模板不是秘密扫描器，请自己检查。
.env
.env.*
!.env.example
*.pem
*.key
id_rsa
id_ed25519
# 临时日志与系统文件
*.log
Thumbs.db
.DS_Store
# 按项目需要补充数据与模型目录，不要误忽略实际源码。
```
