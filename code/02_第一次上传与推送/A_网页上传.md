# 文件夹二 A：网页直接上传

适用：少量文件、偶尔提交，不需要上传已有本地 Git 提交历史。
1. 打开目标仓库，确认账号、仓库和分支。
2. 已有文件的仓库：Add file → Upload files。空仓库：Quick setup 中 uploading an existing file。
3. 拖入需要上传的文件或文件夹。保留目录结构，检查不要多套一层项目目录。
4. 检查列表，不上传 .git、.env、私钥、虚拟环境或不需要的大文件。
5. 输入提交说明，例如“首次上传代码”，再 Commit changes。
6. 刷新仓库页面，核对文件路径和内容；受保护分支可能要求新分支和 Pull Request。
浏览器上传单文件限制为 25 MiB；更大的文件请改用 Git，超过 100 MiB 使用 Git LFS 等合适方式。
这是网页生成的新提交，不会导入本地原有提交历史。网页方法没有必须执行的本地 Git 代码。
