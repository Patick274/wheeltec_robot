# 文件夹三 A：网页下载 ZIP 与上传

1. 在仓库 Code 菜单选择要下载的分支，再 Download ZIP，解压后编辑。
2. 下载的是该版本的文件快照，没有 .git 和本地 Git 提交历史，不能直接在其中 git pull。
3. 准备上传前重新查看远程是否有他人更新，逐文件比较自己的修改。
4. 回仓库目标分支 Add file → Upload files，检查路径、填写说明后 Commit changes。
5. 网页上传不会自动表达本地删除：需要删除的远程文件，应在网页单独检查后删除。
不要把一份旧 ZIP 的全部文件盲目覆盖回去；两台电脑长期交替开发建议选择 B/C/D。
此方式没有本地 pull/push 命令。
