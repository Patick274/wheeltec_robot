# 双机每日交接清单

当前仓库：Patick274/wheeltec_robot，分支 main，远程别名 origin。
A：Windows/PHM；B：Linux 的 ~/projects/wheeltec_robot（本教程选定路径）。
先看 [A/B 简明流程](GitHub_AB两机同步简明流程.md)，打印使用 [4 页 PDF](../output/pdf/GitHub_AB两机上传下拉简明手册.pdf)。

## 开工

- [ ] 终端和编辑器打开的是同一个正确克隆目录。
- [ ] git branch --show-current 显示目标分支。
- [ ] git status 没有未处理修改、merge 或 rebase。
- [ ] git pull --ff-only 成功；有报错先停下。
- [ ] 最新提交符合另一台电脑的交接记录。

## 收工

- [ ] 保存文件，git diff 检查本次修改。
- [ ] 仅暂存所需文件，git diff --cached 检查实际提交内容。
- [ ] 完成项目自己的必要检查；不把不完整功能混进稳定 main。
- [ ] git commit -m "本次改动" 成功。
- [ ] git push 成功，网页相同分支看到新提交。
- [ ] 记录当前分支、提交短编号和未完成事项。

## 交接记录模板（复制填写）

```text
日期：
来源电脑：A / B
仓库：Patick274/wheeltec_robot
分支：main
最后提交短编号：
push 是否成功：
已完成：
待完成：
验证情况：
未进入 Git 的数据或环境文件：
```

stash、.venv、被忽略数据不会随着普通 push 传到另一台电脑。
