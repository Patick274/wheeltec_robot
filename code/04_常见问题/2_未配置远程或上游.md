# 问题 2：没有推送目标或上游

No configured push destination 表示没有可用的推送目标；no upstream branch 常表示当前分支没有上游。
```powershell
git remote -v
git branch -vv
git branch --show-current
# 分别检查远程地址、分支上游、当前分支名。
```
没有 origin 时（下面 URL 按实际替换）：
```powershell
git remote add origin https://github.com/YOUR-USER/PHM.git
git push -u origin main
# 当前分支确实为 main 且有提交时执行；其他分支用自己的名称。
```
已有 origin 地址写错时：git remote set-url origin 正确URL。
已有 origin、只是当前分支没上游：git push -u origin 当前分支名。
认证失败或没有写权限是另外的问题，检查登录账号、仓库权限及组织规则。
