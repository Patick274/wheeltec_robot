# 问题 3：src refspec main does not match any

原因：本地没有名为 main 的可推送提交引用，可能分支名不同，也可能尚未首次提交。
```powershell
git branch --show-current
# 看实际分支名；未首次提交时 git branch 的普通列表可能为空。
git log --oneline -5
# 无提交时会提示当前分支尚无提交，这也是诊断结果。
git status
```
无提交：先准备实际文件和 .gitignore，然后 git add .、git commit -m "首次提交"，再 push。
分支叫 master：git push -u origin master；不要照抄 main。
确实要把当前分支改为 main 且 main 不存在：git branch -m main，再 git push -u origin main。
空目录不会被 Git 记录，需先添加文件。
