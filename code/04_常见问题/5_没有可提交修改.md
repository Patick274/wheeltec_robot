# 问题 5：nothing to commit, working tree clean

这是状态说明，不一定是故障：本地没有待提交修改，不等于没有待推送提交。
```powershell
git status
git log --oneline -5
git branch -vv
git remote -v
# 确认是否已有本地提交，以及当前分支是否 ahead（领先上游）。
```
已有本地提交及上游：git push；已有提交但无上游：git push -u origin 当前分支名。
如果明明新增了文件却没显示：确认编辑器已保存、当前目录正确、文件是否被忽略。
```powershell
git status --ignored --short
git check-ignore -v -- '实际文件路径'
# 显示是否被忽略及命中的规则；不匹配规则时 check-ignore 返回非零是正常结果。
```
不要为了消除提示反复创建空提交，也不要把密钥等被正确忽略的文件强制加入。
