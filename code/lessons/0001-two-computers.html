PHM · 10 分钟短课

把 A 的一次改动交给 B

目标：能说清修改在哪一步离开 A，并用提交编号核对 B 是否拿到同一版本。

以下为练习指导，不会自动操作仓库。先在练习仓库使用，所有命令报错后停止。

先记住四步

保存 → git add → git commit → git push

前面三步都发生在 A。push 成功后，B 才能从 GitHub 拉取。网页要选择同一分支。

用一次小改动练习

  1. 在 A 确认分支和干净工作区，pull --ff-only。
  2. 在已有练习 README 添加一行双机交接说明，保存、暂存、检查并 commit。
  3. 先停下来查看网页：此时没有新提交是正常的。
  4. push 后刷新网页，记录最新短编号。
  5. 在 B 确认同仓库、同分支、干净工作区，pull --ff-only；核对 git log -1 --oneline。

立即自测

A 已 commit，B 何时能从 GitHub 获取这次改动？

过两天再回忆

不看上文，说出“开工”和“收工”的动作，以及 clean 为什么不等于上传成功。
