开工先拉，收工先交接

开工 / 工作区干净且在目标分支

git branch --show-current
git status
git pull --ff-only

收工 / 保存并检查

git add -- '实际文件路径'
git diff --cached
git commit -m "说明本次修改"
git push
git log -1 --oneline

网页同一分支核对提交短编号；报错就停。新分支第一次推送需 git push -u origin 分支名。

术语表

术语含义
Git / GitHub本地版本工具 / 远程托管平台
工作区 / 暂存区正在编辑的文件 / 准备提交的内容
commit / push形成本地提交 / 上传提交并更新远程引用
clone / fetch / pull首次克隆 / 获取远程信息 / 获取并整合进当前分支
origin / main / HEAD远程别名 / 分支示例名 / 当前检出的引用
origin/main本机最近 fetch 掌握的远程 main 位置
stash仅本机的临时保存，不随 push 上传
Pull Request请求合并分支，不等于 git pull
