## 核心流程演练

使用临时目录中的一个本地裸仓库模拟远程，A、B 两个独立克隆模拟两台电脑。
未连接 GitHub、未触碰真实 PHM 的 Git 元数据，未改动全局配置；临时演练目录结束后清理。

通过项目：

- 两份独立克隆、origin 与上游建立成功
- 工作区 clean 时仍可有一个未推送提交
- A push 后 B 快进拉取，提交编号一致
- add 后再编辑，commit 默认只包含已暂存版本
- 分叉被检测；快进停止；merge 保留双方提交并可普通推送
- 同一行冲突、merge --abort、rebase 解决后 continue 和普通 push
- stash -u 收起未跟踪文件但不含忽略文件；apply 后记录保留
- 功能分支在 A 推送后，可在 B 跟踪接手
- 已推送普通提交可 revert；历史仍可查看并建立救援分支
