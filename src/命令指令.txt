================================================================
        Wheeltec 机器人 ROS Noetic (ARM64) 导航命令手册
              适配版本日期:2026-08-25
================================================================

【环境说明】
- 系统:aarch64 (ARM64) + ROS Noetic + Python3
- 底盘:wheeltec 差速底盘(2 驱动轮 + 4 万向轮),car_mode = mini_diff
- 雷达:镭神 M10 × 2(双雷达模式 ls_M10_double)
- 导航栈:apt 安装的 noetic 官方包(amcl / move_base / map_server /
  gmapping / teb_local_planner / robot_pose_ekf)
- 工作空间只保留 6 个包:
    turn_on_wheeltec_robot  核心:底盘串口驱动、launch、导航参数、地图
    lsm10_v2                镭神 M10 雷达驱动
    rrt_exploration         RRT 自主探索建图
    world_canvas_msgs       地图保存服务(rrt_exploration 依赖)
    wheeltec_robot_rc       键盘遥控
    wheeltec_joy_control    手柄遥控

================================================================
一、编译工作空间(修改代码后执行)
================================================================
cd ~/wheeltec_robot
rm -rf build devel          # 彻底重编时先清理(平时可省略)
source /opt/ros/noetic/setup.bash
catkin_make

# 每次开新终端都要 source(建议写入 ~/.bashrc):
source ~/wheeltec_robot/devel/setup.bash

================================================================
二、最小启动:底盘 + 雷达(自检用)
================================================================
roslaunch turn_on_wheeltec_robot turn_on_wheeltec_robot.launch

说明:启动以下节点——
  1. wheeltec_robot_node  底盘串口节点(默认串口 /dev/wheeltec_controller,
     115200),订阅 /cmd_vel 控制电机,发布轮式里程计
  2. robot_pose_ekf       融合轮式里程计 + IMU,发布 odom_combined →
     base_footprint 的 TF
  3. robot_state_publisher + 静态 TF(含雷达安装位置)
注意:此 launch 不含雷达。雷达由建图/导航 launch 自动启动,
     也可单独启动验证:
roslaunch lsm10_v2 lsm10_v2.launch      # 默认双雷达(if_double:=true)

验证雷达数据:
rostopic echo /scan --noarr             # 看是否有数据刷屏
rostopic hz /scan                       # 看发布频率

附加
  # 导航(和之前一样, twist_mux 随底盘自动启动)
  roslaunch turn_on_wheeltec_robot navigation.launch

  # 需要手柄接管时, 另开终端
  roslaunch wheeltec_joy joy_control.launch

  行为：导航正常跑；手柄一推立即接管；松手后机器人立即停下，0.5 秒后导航自动恢复继续走向目标。

================================================================
三、遥控(建图时用)
================================================================
键盘遥控(新终端):
roslaunch wheeltec_robot_rc keyboard_teleop.launch
# 按提示按键移动(u/i/o/j/k/l/m/,/.),k 急停,q/z 加减速度

================================================================
四、建图(gmapping)
================================================================
roslaunch turn_on_wheeltec_robot mapping.launch

说明:
  - 自动启动:底盘节点 + 双 M10 雷达 + gmapping 建图 + EKF 滤波
  - 默认算法 gmapping;可选 hector/karto/cartographer:
      roslaunch turn_on_wheeltec_robot mapping.launch mapping_mode:=karto
    (hector/cartographer 需自行安装对应包)
  - 用键盘遥控小车走遍整个区域,建图效果可在 rviz 中查看:
      rviz    # 添加 Map 显示,话题 /map

【保存地图】二选一:
  方式1(一键保存,保存为 map/WHEELTEC.pgm 和 WHEELTEC.yaml):
      roslaunch turn_on_wheeltec_robot map_saver.launch
  方式2(手动指定文件名):
      cd ~/wheeltec_robot/src/turn_on_wheeltec_robot/map
      rosrun map_server map_saver -f mymap
      # 生成 mymap.pgm 和 mymap.yaml

================================================================
五、导航(核心任务)
================================================================
1) 先修改导航使用的地图文件:
   编辑 ~/wheeltec_robot/src/turn_on_wheeltec_robot/launch/navigation.launch
   找到这一行:
     <arg name="map_file" default="$(find turn_on_wheeltec_robot)/map/third.yaml"/>
   把 third.yaml 改成你保存的地图名,例如:
     <arg name="map_file" default="$(find turn_on_wheeltec_robot)/map/mymap.yaml"/>

2) 启动导航:
   roslaunch turn_on_wheeltec_robot navigation.launch

   自动启动:底盘 + 双雷达 + map_server(加载地图) + amcl(定位)
            + move_base(teb 局部规划器) + send_mark.py(多点巡航)

3) rviz 操作:
   rviz
   - 先用 "2D Pose Estimate" 给定初始位姿(amcl 需要)
   - 用 "2D Nav Goal" 点击目标点,小车自动规划路径前往

【多点巡航】send_mark.py 已随 navigation.launch 自动启动:
   - rviz 工具栏 "Publish Point" 连续点击多个目标点,
     小车到达一个后自动前往下一个,全部到达后循环巡航
   - 在运行 send_mark 的终端按 'c' 清空所有目标点

【备选:图形化导航控制台】(需图形界面)
   roslaunch turn_on_wheeltec_robot rviz_nav_console.launch
   (需先启动 navigation.launch)

================================================================
六、RRT 自主探索建图(可选:不用遥控,小车自己探索)
================================================================
roslaunch turn_on_wheeltec_robot rrt_slam.launch

说明:
  - 在建图(mapping.launch navigation:=true)基础上叠加 RRT 边界
    检测节点(global/local detector + filter + assigner)
  - 小车自动朝未知区域边界移动,无需人工遥控
  - 建完图同样用第四节的方法保存地图

================================================================
七、常用调试命令
================================================================
roscore                              # 单独启动 roscore(一般用不上,roslaunch 自带)
rosnode list                         # 查看运行中的节点
rostopic list                        # 查看所有话题
rostopic echo /scan --noarr          # 查看雷达数据(不打印数组)
rostopic echo /odom                  # 查看里程计
rosrun tf view_frames                # 生成 TF 树 pdf(当前目录 frames.pdf)
rosrun tf tf_echo map base_footprint # 查看定位 TF 是否正常
rosrun rqt_graph rqt_graph           # 节点关系图(需图形界面)
rosrun rqt_tf_tree rqt_tf_tree       # 实时 TF 树(需图形界面)

# 串口权限问题(报 permission denied 时):
sudo chmod 777 /dev/wheeltec_controller
# 长期方案:执行一次 udev 脚本(已随包提供)
sudo ~/wheeltec_robot/src/turn_on_wheeltec_robot/scripts/wheeltec_udev.sh

八、关键参数文件位置(需要按实机核对/调整)
================================================================
1) 机器人外形(影响避障!按实机尺寸修改):
   turn_on_wheeltec_robot/costmap_common_params/param_mini_diff/
     costmap_common_params.yaml  → footprint(默认约 23×18cm)

   turn_on_wheeltec_robot/launch/robot_model_visualization.launch
   搜索 "mini_diff",修改 base_to_laser 一行
4) 通用导航参数(全局/局部代价地图、amcl、move_base):
   turn_on_wheeltec_robot/param_common/*.yaml
5) 底盘串口参数:
   turn_on_wheeltec_robot/launch/include/base_serial.launch
   (串口设备名、波特率、坐标系名称)
6) 雷达扫描范围/屏蔽角度:
   turn_on_wheeltec_robot/launch/wheeltec_lidar.launch
